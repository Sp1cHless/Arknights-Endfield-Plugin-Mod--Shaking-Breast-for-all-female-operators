终末地胸部晃动管理器
用户手册
========================

本手册介绍 跳跃柰子管理器的基本使用方法。

Manager 一共有四个主要页面：

    1. 主界面
    2. 角色
    3. 预设
    4. 开发者

大多数普通用户只需要使用 主界面、角色。
开发者 主要用于维护者录入和支持新角色。


============================================================
1. 快速开始
============================================================

基本使用方法：

1. 按照发布说明下载并解压工具包。
2. 启动 Manager，并选择游戏文件夹。
   例如：
   E:\\......\\Hypergryph Launcher\\games\\Endfield Game
3. 启动《明日方舟：终末地》。
   Manager 和游戏谁先启动都可以。
4. 等待 Manager 显示游戏和插件已可用。
5. 进入游戏，并切换到一个已支持的角色。
6. 打开 Main 页面。
7. 如有需要，启用该角色的插件功能。
8. 选择一个运动模式：默认Synthetic

9. 如果使用 Synthetic 模式，可按需要调整 行走，跑动，冲刺，挂滑索 参数。

   进阶参数中的3个
   平滑参数会影响动画状态切换时的表现，
   例如从跑步切换到停止时的胸部运动。

一般来说，其他的不用碰

10. 点击 应用。修改会在游戏运行过程中直接生效，不需要重启游戏。
11. 切回游戏查看实际效果。
12. 如有需要，继续调整并重复 应用。

Manager 是一个独立于游戏之外运行的工具，不需要游戏内 UI。


------------------------------------------------------------
三种运动模式
------------------------------------------------------------

Original
    不对当前角色写入任何自定义 Secondary Motion。

    使用该模式可以让角色恢复游戏原本的动画 / 次级运动表现。


Synthetic —— 推荐使用
    根据角色当前的移动状态生成可配置的 Secondary Motion。

    Walk、Run、Sprint 等状态可以分别设置不同的幅度和频率。


Amplify Native —— 对大多数角色来说效果并不理想
    放大游戏原本已经存在的运动，
    而不是使用 Synthetic 的自定义振荡。

    使用 原生增益 参数控制放大强度。


============================================================
2.  主界面
============================================================

主界面是查看当前运行状态、并快速调整当前主控角色的页面。

常见状态信息包括：

游戏状态
    显示当前是否检测到游戏。

插件状态
    显示注入到游戏中的 Runtime / 插件是否可用。

当前主控角色
    显示当前检测到的主控角色。

预设
    显示当前使用的预设。


------------------------------------------------------------
角色启用开关
------------------------------------------------------------

对该角色启用插件
    启用当前角色 / 配置文件的自定义处理。

关闭后，角色应该恢复游戏原本的行为。


------------------------------------------------------------
模式
------------------------------------------------------------

可以选择：

    Original
    Synthetic
    Amplify Native


------------------------------------------------------------
移动状态参数
------------------------------------------------------------

Synthetic 模式可以分别设置： 行走，跑动，冲刺，挂滑索

每个状态通常包含：

Amplitude（幅度），向上和向下是分开的，看你喜欢
    控制生成运动的旋转幅度 / 强度。

Frequency（频率）
    控制生成的周期运动速度。

Amplitude 越高 = 运动幅度越大。
Frequency 越高 = 运动越快。

通常不需要修改 Frequency，
因为默认值已经按照游戏动画的频率进行了调整。


------------------------------------------------------------
高级设置
------------------------------------------------------------

振幅缩放
    对当前角色生成的整体幅度进行倍率调整。

    不同角色的骨骼结构和模型不同，
    即使使用同样的角度，也可能产生不同的视觉效果，
    因此这个数值可以按角色单独设置。


Axis（运动轴）
    设置当前角色配置所使用的旋转轴。

    常见选项：
        X —— 目前还没有角色使用
        Y
        Z

    对于已经验证好的角色，
    普通用户一般不需要修改该参数。


Direction（方向）
    设置旋转轴的正 / 负方向。

    常见选项：
        +
        -


注意：
平滑参数会影响动画状态切换时的运动表现，
例如从跑步切换到停止时的效果。


不同动作间过渡平滑
    控制角色在 走跑冲 等状态之间切换时，
    幅度变化的平滑程度。

    数值越大：
        变化越慢、过渡越柔和

    数值越小：
        变化越快、响应越直接


频率平滑
    控制在应用平滑时，运动频率变化的速度。

    数值越大：
        频率变化越缓慢

    数值越小：
        频率响应越快


运动到静止停止平滑
    控制角色从 走跑冲 等移动状态回到停止状态时，
    运动结束的平滑程度。

    数值越大：
        停止得更慢

    数值越小：
        更快稳定下来


平滑参数使用示例：

如果：
    过渡平滑 = 1
    静止平滑 = 0.5

那么过渡阶段的额外晃动会更少、更慢，也会更快停止，
整体感觉会更“沉”。

如果：
   过渡平滑 = 0.5
   静止平滑 = 1

那么停止前会出现更多、更频繁的余振，像水球一样弹跳。


Native Amplify（原生运动放大）
    Amplify Native 模式使用的放大倍率。

    这个参数与 Synthetic 的 Amplitude 是不同的。


Jump
    某些开发版 UI 中可能仍然会显示旧的 Jump / Landing 功能。

    该功能目前不属于主要支持范围，
    一般建议保持关闭。


------------------------------------------------------------
应用
------------------------------------------------------------

修改参数后点击 应用。

成功应用后，Manager 应显示对应的成功 / 已确认状态。

如果 应用 报错，不要默认认为游戏已经接受了新的设置。


============================================================
3. 所有角色
============================================================

Characters 页面用于编辑某一个指定角色的设置，
而不仅仅是当前正在控制的角色。

页面通常包含主界面参数，可以调整

------------------------------------------------------------
角色列表
------------------------------------------------------------

从列表中选择一个角色，
即可编辑该角色在当前 预设 中的配置。

这里选择的角色不一定必须是游戏中当前正在控制的角色。


------------------------------------------------------------
按角色独立设置
------------------------------------------------------------

每个支持的角色都可以拥有独立参数。

这是有意这样设计的。

不同角色的骨骼和模型结构不同，
相同的数值可能产生完全不同的视觉效果，
因此不假设一套全局参数能够适用于所有角色。


------------------------------------------------------------
从预设中删除
------------------------------------------------------------

    该操作会从数据库 / 当前配置中移除所选角色的用户覆盖数据，
    之后需要重新扫描 / 录入该角色。


============================================================
4. 预设 页面
============================================================

预设 用于保存用户的运动参数偏好。

默认角色数据库中保存的是技术信息，
例如骨骼映射、Axis 等；

预设 主要用于保存用户层面的设置，
例如运动模式、幅度和其它参数。

Default，工具最开始自带的参数是根据我自己的游戏调的，请调整自己的并保存预设

------------------------------------------------------------
 分享
------------------------------------------------------------

分享的 preset 主要应该包含用户的运动偏好。

骨骼名称等角色兼容性技术数据应该来自工具自带的角色数据库，
而不是要求每个用户 preset 都重新定义一遍。


============================================================
5. 开发者页面
============================================================

============================================================
录入新角色
============================================================

重要：
    本部分主要面向维护者 / 开发者。

    在把角色加入默认数据库之前，
    应先确认左右骨骼、Axis、Direction 以及基本运行效果。


------------------------------------------------------------
STEP 1 — 检测角色
------------------------------------------------------------

1. 进入游戏。
2. 切换到尚未支持 / 新加入的角色。
3. 打开 Developer 页面。
4. 查看检测到的角色 ID / canonical ID。

正常会类似：

    chr_xxxx_name

这个名字是游戏公司内部使用的角色命名，
所以看到一个与你熟悉的角色正式名称不一致的名字是正常的。

类似 Clone / object instance 的运行时后缀
不应该成为 canonical character ID 的一部分。


------------------------------------------------------------
STEP 2 — 扫描骨骼
------------------------------------------------------------

运行 Skeleton / Bone Scanner。

扫描可能需要等待几秒；
如果没有马上出现结果，也可以再次点击 Scan。

扫描完成后会显示找到的所有骨骼。

可以使用 Filter 过滤需要的骨骼，
通常可以搜索：

    breast
    xiong

你通常会找到类似下面结构的骨骼：

    xiong_R_0_skin_jnt
    breast_R_01_jnt

有时可能会出现多个相似结果。


------------------------------------------------------------
STEP 3 — 选择左右骨骼
------------------------------------------------------------

研究中常见的骨骼命名包括：

    breast_R_01_jnt / breast_L_01_jnt
    R_breast_01_jnt / L_breast_01_jnt
    xiong_R_0_skin_jnt / xiong_L_0_skin_jnt


对于 “xiong”：
    一般选择 R_0，而不是 R_1。

对于 “breast”：
    一般选择 R_1，而不是 R_2。


这些只是目前研究中常见的例子。

对于未知角色，不要在没有验证的情况下
直接假设一定使用这些骨骼。

使用页面下方的按钮分别选择左 / 右骨骼。


------------------------------------------------------------
STEP 4 — 保存 / 发布角色
------------------------------------------------------------

你可以填写该角色的显示名称。

如果不填写，
角色将直接显示为：

    chr_xxxx_name

之后也可以随时在 Characters 页面中修改显示名称。

完成后点击 SAVE。

必须先保存，角色才能正常使用。


------------------------------------------------------------
STEP 6 — 验证
------------------------------------------------------------

点击 Validate，
检查角色录入所需的信息是否完整。

目前作者已经使用该工具录入全部角色，
整体没有发现明显录入错误。

完整验证通常至少应确认：

    Character ID 有效
    右侧骨骼存在
    左侧骨骼存在
    左右骨骼不是同一个
    Axis 有效
    Direction / Sign 有效
    Scale 有效
    Gait Amplitude 有效
    Gait Frequency 有效
    Runtime 写入正常
    测试期间没有 Runtime 错误


============================================================
7. 基础故障排查
============================================================

Game 显示 Not Running
    确认游戏确实已经启动。

    Manager 不要求一定先启动游戏，
    两者启动顺序可以互换。


Plugin 显示 Not Ready
    检查 Runtime DLL 是否已经安装到正确的插件目录。

    如果有日志，可以查看 Runtime log。


检测到角色，但没有运动效果
    确认：
        - 该角色已经被支持
        - 角色 Enable 已打开
        - Mode 不是 Original
        - Profile / Bones 已找到
        - Apply 已成功完成


修改数值没有效果
    点击 Apply，
    并确认 Manager 显示新的配置已经成功应用。

    仅仅修改输入框数值，不应默认认为游戏已经更新。

    可以临时使用一个明显更大的数值（例如 100）
    来快速确认功能到底有没有生效。


只有某一个角色效果不对
    使用该角色自己的独立设置进行调整。

    不要因为一个角色的问题，
    就直接修改所有角色的全局参数。


不支持 / 新角色
    如果不是在使用 Developer Mode 主动录入角色，
    建议让该角色保持 Original / Native 行为。


============================================================
8. 参数速查
============================================================

Amplitude
    运动幅度 / 旋转强度。

Frequency
    振荡频率，单位 Hz。

Amplitude Scale
    角色级别的幅度倍率。

Axis
    X / Y / Z 旋转轴。

Direction
    旋转轴正 / 负方向。

Env Attack Tau / Transition Smoothing
    幅度响应 / 过渡平滑。

Env Freq Tau / Frequency Smoothing
    频率变化平滑。

Env To-Idle Tau / Stop Smoothing
    停止 / 回到 idle 时的平滑。

Native Amplify
    Amplify Native 模式的放大倍率。


============================================================
9. 重要说明
============================================================

- 参数是按角色分别设置的。
- 对未知角色不要使用猜测的骨骼参数，应保持原版行为。
- 本工具主要针对当前主控角色。
- 后台队友的运动效果不属于主要功能目标。
- Jump 自定义运动目前不属于主要支持功能。
- 游戏版本更新后可能需要更新 Runtime / 插件兼容性。
- 除非发布说明明确要求，否则请保持整个发布文件夹结构不变。


============================================================
10. 卸载流程
============================================================


1. 退出游戏
2. 删除 \Secondary Motion 文件夹，位置在终末地根目录（就是第一次打开exe选择那个）.
3. 删除终末地根目录下的  \plugin 文件夹. ***注意****， 一定是'plugin'，里面有sbm.dll，不是'plugins'后面有个s，那是游戏自己的插件文件夹，别碰
4. 游戏根目录下找到d3dcompiler_47.dll，vulkan-1.dll删掉。他们旁边会找到d3dcompiler_47.dll.bak和vulkan-1.dll.bak，将他们的.bak去掉，就是游戏原来的dll了。
5. 删掉解压出来的整个工具的文件夹
6. 卸载完成。
